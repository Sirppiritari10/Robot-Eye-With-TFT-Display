How to connect the board to WiFi (short guide)

The ESP32 connects automatically using the WiFi settings defined in the code:

Set your network here:
const char* WIFI_SSID = "your_wifi_name";
const char* WIFI_PASSWORD = "your_password";
On startup, the board runs connectWiFi():
Sets WiFi mode to station mode (client)
Tries to connect using the given SSID and password
Waits until WiFi.status() == WL_CONNECTED
Once connected:
It prints the IP address over Serial
That IP is also shown on the TFT screens until the first command is received
You use that IP to send WebSocket commands to port 8765


Short summary of the control scheme

The eyes are controlled remotely over WiFi using WebSocket messages with JSON commands sent to an ESP32.

How to control the eyes

You send JSON with a "cmd" field:

"look" → moves both eyes
Send { "cmd": "look", "value": { "x": ..., "y": ... } }
→ controls eye direction.
"state" → changes eye state (like open/closed/other presets)
→ Eyes.setEyePairState(...)
"mood" → changes expression/mood (affects eye appearance)
"pupilR" → sets pupil size
→ value.r controls radius
"blink" → triggers blink animation
"glance" → quick eye movement (can be random or given x/y)
How to add new eye controls

To add a new command:

Add a new else if (strcmp(cmd, "yourCommand") == 0) block inside handleCommand().
Read optional values from doc["value"].
Call or create a function inside Eyes (the Eye_Pair class) to perform the behavior.
Implement that function in Robot_Eye / Robot_Eye_Pair.

In short:
All eye control is centralized in handleCommand() and executed through the Eyes object.
